OMUR DESK ENGINE
================
Free browser-only stock metadata generator.

Files:
- index.html
- style.css
- app.js

How to use:
1. Open index.html in a browser.
2. Upload one or many JPG/PNG/WebP images.
3. Choose platform, category and keyword count.
4. Click Generate Metadata.
5. Copy metadata or download CSV.

Unlimited:
There is no built-in generation counter or daily limit. This version uses a local rules/dictionary engine, so it does not consume an AI API quota.

Important:
A true AI image-understanding generator requires an AI model/API. Do not put a secret API key directly in frontend JavaScript. For a future AI version, use a small backend/serverless function to protect the key.
